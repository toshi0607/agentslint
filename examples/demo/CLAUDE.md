# acme-app

A sample web app. This file demonstrates the kinds of config rot agentslint catches —
run `npx @toshi0607/agentslint` in this directory.

Read @docs/architecture.md before making changes.

## Conventions

Follow [the style guide](./docs/style-guide.md) for naming rules.

## Commands

- `npm run dev` — start the dev server
- `npm run typecheck` — run the type checker before committing
